# Kalóriaszámláló

Egy kalória tracking asztali alkalmazás JavaFX-ben, SQLite adatbázissal. 
Az adatbázisban alapból van pár mindennapi étel, lehet felhasználókat létrehozni, és naplózni a reggelit, ebédet, vacsorát meg a nasit. A megadott adatok (magasság, testsúly, kor) alapján kiszámolja, hogy egy nap alatt kb mennyi kcal jut az egyes étkezésekre. Ha változik a súly, frissíteni lehet, és vele együtt frissül a napi kcal is.

## Funkciók

- Felhasználók létrehozása, törlése
- Napi étkezések naplózása
- Új ételek hozzáadása naplózáshoz
- Ételek tápértékének számolása
- Szükséges napi táplálék kiszámítása
